Course Descriptions

  • IT101 - Introduction to Programming: Fundamentals of programming using Python and problem-solving techniques.

  • IT301 - Computer Networks: Principles of data communication, network protocols, and architecture.
  • IT302 - Web Development: Building modern web applications with HTML, CSS, JavaScript, and frameworks.
  • IT401 - Cybersecurity Fundamentals: Introduction to security principles, threats, and defensive strategies.
